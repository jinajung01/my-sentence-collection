# 내 문장 모음 (My Sentence Collection)

웹페이지에서 마음에 드는 문장을 드래그하고 **우클릭 한 번**으로 출처와 함께 저장하는 크롬 확장 프로그램입니다.

- Manifest V3
- 권한 2개만 사용: `contextMenus`, `storage`
- 외부 라이브러리와 외부 서버 요청 없음

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 우클릭 저장 | 문장을 선택하고 우클릭 → **내 문장 모음에 저장**. 페이지 제목과 주소가 출처로 함께 저장됩니다. |
| 중복 방지 | 같은 페이지의 같은 문장은 다시 저장하지 않고, 아이콘에 `중복`을 잠깐 표시합니다. |
| 새 문장 알림 | 아직 확인하지 않은 새 문장 수를 아이콘에 빨간 숫자로 보여 주고, 팝업을 열면 사라집니다. |
| 검색 | 문장 내용, 출처 제목, 주소로 찾습니다. |
| 출처 링크 | 출처를 누르면 원래 페이지가 새 탭으로 열립니다. |
| 복사 | `“문장” — 페이지 제목 (주소)` 형식으로 출처까지 함께 복사합니다. |
| 형광펜 | 팝업에서 문장 일부를 드래그하면 형광펜을 그을 수 있고, 그은 부분을 누르면 지워집니다. |
| 태그 (선택) | 문장마다 태그를 하나 달고, 태그로 걸러 볼 수 있습니다. 태그를 지워도 문장은 남습니다. |
| 삭제 | 문장 하나씩 지우거나, 확인을 거쳐 전체를 지울 수 있습니다. |

## 설치 방법

1. 이 저장소를 내려받습니다. (**Code → Download ZIP** 후 압축 풀기, 또는 `git clone`)
2. 크롬 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고, `manifest.json`이 들어 있는 폴더를 선택합니다.
5. 툴바의 퍼즐 아이콘에서 **내 문장 모음**을 고정하면 편합니다.

파일을 고친 뒤에는 `chrome://extensions`에서 이 확장 프로그램의 **새로고침(↻)** 버튼을 눌러야 반영됩니다. 크롬이 실제로 읽는 폴더는 확장 프로그램 **세부정보 → 출처(로드 위치)**에서 확인할 수 있습니다.

## 사용 방법

1. 웹페이지에서 저장할 문장을 드래그합니다.
2. 우클릭 → **내 문장 모음에 저장**을 누릅니다.
3. 툴바의 확장 프로그램 아이콘을 누르면 저장한 문장을 볼 수 있습니다.

## 파일 구성

| 파일 | 하는 일 |
| --- | --- |
| `manifest.json` | 확장 프로그램 이름, 버전, 권한, 백그라운드 스크립트와 팝업을 정합니다. |
| `background.js` | 우클릭 메뉴를 만들고, 선택한 문장과 출처를 저장하고, 아이콘 숫자를 관리합니다. |
| `popup.html` | 팝업 화면의 구조와 스타일입니다. 다크 모드를 지원합니다. |
| `popup.js` | 목록, 검색, 복사, 형광펜, 태그, 삭제 등 팝업 동작을 처리합니다. |

## 데이터 저장에 대해

- 문장은 `chrome.storage.local`에 저장됩니다. **이 컴퓨터의 이 크롬 프로필에만** 저장되며 외부로 전송되지 않습니다.
- 다른 크롬 프로필이나 다른 컴퓨터와는 동기화되지 않습니다.
- 확장 프로그램을 삭제하면 저장된 문장도 함께 지워집니다.

## 문의 메일 설정

팝업 하단의 **email**을 누르면 문의 메일 주소가 보입니다. 주소는 `popup.js` 맨 위의 한 줄에서 바꿉니다.

```js
const CONTACT_EMAIL = "you@example.com";
```

## 알려진 점

- 아이콘 이미지가 없어 크롬 기본 아이콘(이름 첫 글자)이 표시됩니다.
- 선택한 글자가 없으면 우클릭 메뉴에 저장 항목이 나타나지 않습니다. (크롬 기본 동작)
